# Header weather icons

`weather_icons.{c,h}` are generated by `tools/gen_weather_icons.py` (Pillow): ten 24x24 flat-colour
pictograms (sun, moon, cloud-sun, cloud-moon, cloud, rain, showers, snow, fog, storm) as LVGL 9
`lv_image_dsc_t` in RGB565A8, ~1.7 KB each. `weather_service.cpp` maps the Open-Meteo WMO code (and
local night hours) to a `WeatherIcon`; `main_screen.cpp` shows it with `lv_image` next to the
temperature. Original artwork, no licence constraints. Edit the script, not the .c file.
